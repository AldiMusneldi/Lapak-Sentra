# Lapak Sentra

Lapak Sentra is a marketplace prototype designed to connect boarding-house and rental owners with prospective tenants while providing a storefront concept for local home-goods and food businesses.

> **Project status:** Historical team project. The frontend was completed for the original presentation scope, while the Express and MySQL backend remained partially implemented. This repository is preserved as a record of the team's research, UI/UX, and frontend development work.

## Product Scope

- Boarding-house and rental discovery
- Property details, facilities, nearby locations, and reviews
- Tenant account interfaces
- Property-owner dashboard
- Local-business dashboard
- Home-goods and local-food storefront concepts
- Cart, ordering, and payment interface prototypes
- Login and registration interfaces for multiple user roles

## Tech Stack

### Frontend

React, Vite, Redux Toolkit, React Router, Tailwind CSS, Chakra UI, and Axios.

### Backend

Node.js, Express.js, MySQL, JWT, bcrypt, and Multer.

## Repository Structure

- [`frontend/`](./frontend) — React application and interface implementation
- [`backend/`](./backend) — partial Express and MySQL backend source

Detailed frontend documentation is available in [`frontend/README.md`](./frontend/README.md).

## Implementation Status

### Completed for the original presentation scope

- UI/UX implementation based on the team's Figma design
- Multi-role frontend pages and navigation
- Tenant, property-owner, and local-business interfaces
- Housing catalog and property-detail interfaces
- Storefront, cart, order, and payment screens

### Partially implemented

- Account registration and login integration
- Express and MySQL backend
- Property listing API and CRUD source
- Frontend-to-backend integration

### Not completed end-to-end

- Reproducible database setup
- File-upload workflow
- Local-business product backend
- Cart, order, and payment backend
- Production deployment
